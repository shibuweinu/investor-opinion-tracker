# 已登录浏览器适配

默认执行顺序：外置 Chrome/CDP → 其他外置浏览器 → 宿主内置浏览器。不要因为内置浏览器更容易调用就跳过已登录的外置 Chrome。

核心不绑定任何浏览器厂商。宿主 Agent 实现：

```python
class BrowserPort:
    def fetch_timeline(self, user_id: str, page: int, count: int) -> dict: ...
```

实现可使用 Codex 内置浏览器、Playwright、Chrome DevTools 或 WorkBuddy 浏览器工具。会话凭据始终由宿主持有，返回值只包含雪球时间线响应。遇到登录、验证码或风控立即返回可恢复状态，不尝试绕过。

分页边界必须取最后一条非置顶普通时间线记录，禁止取整页最小时间。相邻页必须按平台帖子 ID 去重。

同一次运行的限速必须跨账号共享，不能在切换博主时重置；请求间隔应在 `1/qps` 基础上加入少量抖动。
早晚报使用成功检查点作为采集截止边界，避免每次重新抓取完整历史上下文。登录失效与访问验证必须
分别报告；出现滑块或风控后立即停止剩余账号，不自动重试，也不切换会话绕过。
